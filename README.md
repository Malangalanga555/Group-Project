# Khwezi Mining Health, Safety & Equipment Monitoring App


## How to run
1. Install the packages: pip install streamlit pandas
2. Start the app: streamlit run app.py

# Files
- app.py: login and role-based menu
- users.py: add and remove users
- worker_safety.py: worker safety records and warnings
- incidents.py: incident database, search, filters, trends and risk scores
- equipment.py: equipment monitoring and maintenance
- dashboard.py, alerts.py, analysis.py, reports.py
